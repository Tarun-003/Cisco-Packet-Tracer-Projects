# 📌 Lab 03 - OSPF Routing

## Objective

Configure dynamic routing using OSPF between six LANs connected using six Cisco routers.

---

## Network Topology

![OSPF Network Topology]{Topology.png)

---

## Devices Used

* 6 Cisco Routers
* 6 Cisco Switches
* 12 PCs

---

## IP Addressing

* LAN Networks: `192.168.10.0/24` – `192.168.60.0/24`
* Router-to-Router Networks: `172.16.0.0` – `172.21.0.0`
* LAN Gateway: `.254`

---

## ⚙️ Routing Protocol

**OSPF – Area 0**
